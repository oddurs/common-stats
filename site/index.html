StatBar

System stats for the menu bar. Small type, small graphs, nothing else.

Download for Mac View on GitHub ›

Free and open source · macOS 14 or later · Apple silicon and Intel

Thu 9:41 AM

Native.

The menu bar tints it like the clock. The dropdown is a real menu. Settings looks like System Settings. VoiceOver reads every value.

Accurate.

The same kernel counters Activity Monitor reads, with tests that compare them against vm_stat and netstat. A value it can't read shows as a dash, never as zero.

Light.

About 0.1 ms to sample everything and 12 MB of memory. It stops drawing when you can't see it and samples less in Low Power Mode.
